## 📖 Project Overview

**Smart File Utility** is a Java-based console application developed as part of my internship assignment. It allows users to perform essential text file operations through an easy-to-use menu-driven interface.

The project demonstrates practical implementation of Java File I/O concepts while following Object-Oriented Programming principles.

---

## ✨ Features

✅ Create a new text file

✅ Write content to a text file

✅ Read and display file contents

✅ Modify existing file contents

✅ Append new content to a file

✅ Delete files safely

✅ Display detailed file information

✅ Input validation and exception handling
